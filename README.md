# Lelux 3D Calculator

App Android per calcolare costi e prezzi di vendita delle stampe 3D FDM e generare preventivi.

- Importa `.3mf` (Bambu Studio / OrcaSlicer, con dati esatti se elaborato), `.gcode` e `.stl` (stima dalla geometria)
- Visualizzatore 3D, miniature automatiche
- Magazzino filamenti e stampanti, catalogo pezzi
- Ricarico in % o utile desiderato in €, canali di vendita con commissioni, arrotondamenti
- Preventivi PDF con logo e miniature, messaggio formattato per WhatsApp/Telegram
- Storico con stati, statistiche ed esportazione CSV
- Tema scuro / chiaro / automatico, "Apri con" dai file del telefono

Ogni push su `main` compila l'APK con GitHub Actions e lo pubblica nel ramo `build-output`.
